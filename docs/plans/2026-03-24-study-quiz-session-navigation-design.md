# 学习会话导航与混合测试模块设计

## 目标

在现有学习模式上增强两个能力：

1. 基于会话队列的“上一个单词 / 下一个单词”导航
2. 面向“已学过单词”的混合测试模式（选择题 + 拼写题）

保持当前学习流程（释义查看、掌握度评分、收藏、快捷键）不回退。

## 范围

- 学习页支持会话队列导航
- 新增学习测试页，题目来源于已学词
- 新增会话状态（队列、索引、已学集合）
- 增加入口从学习页跳转到测试页

不在本期范围：

- AI 情景对话
- 全量 Dashboard 重构
- 完整三阶段解锁体系

## 架构设计

采用“学习页 + 测试页 + 共享会话状态”分层：

1. `Study.vue` 负责学习与会话内前后导航。
2. `StudyQuiz.vue` 负责测试流程与成绩展示。
3. `learning` store 新增会话状态字段与方法，供两页共享。

这样能避免把测试逻辑继续堆进学习页，后续迭代更可维护。

## 数据结构

在学习状态中新增：

- `sessionQueue: string[]`：当前会话出现过的单词（有序去重）
- `sessionWordMap: Record<string, WordDetail>`：会话词详情快照
- `currentSessionIndex: number`：当前词索引
- `learnedWordsInSession: string[]`：当前会话中已打分单词

## 交互规则

### 学习页

- 每次加载新词后，写入会话队列并更新当前位置。
- “上一个”跳转到 `currentSessionIndex - 1`（下限 0）。
- “下一个”优先跳到会话中的后一个词；若已在尾部则继续随机抽新词并入队。

### 测试页

- 题池来自 `learnedWordsInSession` 对应词详情。
- 每题随机题型：
  - 选择题：英文词 -> 4 选 1 中文释义
  - 拼写题：中文释义 -> 输入英文
- 拼写判定忽略前后空格与大小写。
- 完成后展示正确率、错题与重测入口。

## 错误处理

- 会话词为空：学习页禁用“上一个”，下一题仍可随机生成。
- 已学词为空：测试页提示“请先学习并标记至少 1 个单词”。
- 选择题干扰项不足：降级为较少选项，但保证有且仅有一个正确答案。

## 验收标准

1. 学习页可稳定使用“上一个/下一个”在会话队列中切换。
2. 会话切词不影响收藏、发音、释义与评分。
3. 测试页可基于已学词出混合题并给出结果。
4. 空数据场景提示正确且无运行时报错。
5. 新增测试通过且 `npm run build` 通过。
