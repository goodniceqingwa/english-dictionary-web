# 计算机英语学习模块设计

## 目标

在现有词典网站中新增“计算机相关英语专项学习”入口，复用现有学习模式交互（抽词、看释义、掌握度打分、收藏、快捷键），但词源限定为自动筛选出的计算机语义词汇。

## 范围

- 新增计算机英语学习入口（首页与导航可达）
- 新增计算机主题词库自动筛选与构建产物
- 新增专项学习页面（或在学习页支持主题模式）并复用原有学习流程
- 保持现有 `/study` 通用学习模式不变

不在本期范围内：

- 章节课程体系
- 题库化闯关模式
- 后端主题配置中心

## 架构设计

采用“构建期生成主题词表 + 运行时按主题抽词”方案：

1. 构建阶段在 `scripts/build-index.js` 增加计算机词汇筛选逻辑，输出 `public/dictionary/topics/computer.json`。
2. 运行阶段在词典工具层增加主题词读取与随机抽样能力。
3. 学习视图增加“计算机专项”页面，流程与现有 `Study.vue` 对齐，仅替换词源。

该方案能将筛选开销前置，避免学习页实时过滤造成首屏延迟，并让规则演进可追踪。

## 数据规则

### 输入

- `public/dictionary/*.json` 的单词详情
- 索引中的单词基础信息（word、definition）

### 筛选规则

- 正向命中：英文和中文计算机语义关键词（如 computer/software/hardware/program/code/algorithm/database/network/server/api/cache/memory/cpu/gpu/cloud/frontend/backend/compiler/debug/deploy；以及“计算机/编程/算法/数据库/网络/服务器/缓存/内存/前端/后端”等）
- 噪音过滤：对高歧义命中词做排除词和弱命中阈值，减少非计算机场景误收

### 输出

- `public/dictionary/topics/computer.json`：
  - `topic`
  - `version`
  - `buildTime`
  - `count`
  - `words: string[]`

## 页面与路由

- 新增路由：`/study/computer`
- 页面标题：`计算机英语学习`
- 首页“快速开始”新增入口卡片
- 顶部导航和移动菜单新增入口

## 运行时数据流

1. 进入 `/study/computer`
2. 读取主题词表并随机抽取 1 个词
3. 调用现有 `getWordDetail` 获取详情
4. 渲染单词与释义
5. 用户打分后写入原有学习进度
6. 继续从主题词表抽下一个词

## 错误处理

- 主题词表不存在/为空：提示“计算机词库暂不可用”，提供返回通用学习入口
- 单词详情缺失：自动跳过并重抽，不中断学习
- 构建阶段打印筛选统计（命中、排除、最终数量），便于调优

## 测试与验收

验收标准：

1. 首页与导航均可进入计算机英语学习页
2. 计算机学习页仅抽取主题词表中的词
3. 打分、收藏、快捷键行为与通用学习模式一致
4. `npm run build` 成功，且 `computer.json` 被生成

质量检查：

- 抽样 20 个词进行语义人工校验，明显非计算机场景词不超过 2 个
